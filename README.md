# Flemish TV Hub: downloads

Installable APKs of Flemish TV Hub for Android TV and Android phones. The code lives elsewhere;
this repository only holds the releases the apps update themselves from.

- **TV app**: releases tagged `tv-…` (`flemish-tv-hub-tv-<version>.apk`)
- **Phone/tablet app**: releases tagged `phone-…` (`flemish-tv-hub-phone-<version>.apk`)

Both apps offer a newer version when they start, and Settings has a button to check and install.
For personal use only.
